# Polski Quiz (A2–B1)

Веб-приложение: аккаунты, тесты, карточки для повторения слов, панель учителя. Без сборки: откройте `index.html` (нужен интернет — библиотека и база Supabase).

- **Ученик:** регистрация/вход, тесты (выбор и ввод ответа, озвучка 🔊), карточки с интервальным повторением (1/3/7/14 дней), история результатов.
- **Учитель:** создание и правка тестов и вопросов, публикация, массовое добавление слов (`слово ; перевод ; пример`), результаты всех учеников.

## База данных
Supabase-проект `polski-quiz`; схема и RLS-политики заданы миграцией `init_schema`. Ключ в `config.js` публичный (publishable), доступ к данным ограничен RLS.

## Как сделать пользователя учителем
Пользователь сначала регистрируется, затем в SQL Editor Supabase:

    update public.profiles set role = 'teacher' where id = (select id from auth.users where email = 'teacher@example.com');

## Важно
В Supabase → Authentication → Providers → Email можно отключить «Confirm email», чтобы ученики входили сразу после регистрации.

## Вход учеников по личной ссылке
В панели учителя → «Ученики» → «Пригласить ученика»: создаётся ученик и личная ссылка вида `…/Alvento/#invite=<токен>`. Ученик открывает ссылку и сразу входит, без пароля; сессия хранится в браузере. Если данные браузера стёрлись — достаточно снова открыть ссылку. «↻ Новая» отзывает старую ссылку. Серверная часть — Edge Function `students` (`supabase/functions/students`), токены в таблице `student_invites`.

## Доступ по почте (основной способ)
Учитель во вкладке «Ученики» вносит email ученика → ученик сам регистрируется с этим email и своим паролем (вход запоминается). Регистрация с другим email закрыта триггером `check_signup_allowed` в базе. Забыл пароль — «🔑 Новый пароль» у ученика в панели. Роль «учитель» автоматически получают две почты, заданные в `handle_new_user` (владелец и Настя); остальных можно повысить в панели.
