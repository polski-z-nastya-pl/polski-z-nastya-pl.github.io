# Polski Quiz

Веб-приложение с тестами для изучения польского языка. Без сборки и зависимостей: откройте `index.html` в браузере.

Темы: слова, фразы, числа, грамматика, дни и время, смешанный тест. Вопросы с выбором ответа и с вводом, озвучка (🔊, браузерный TTS pl-PL), разбор ошибок, лучший результат сохраняется в localStorage.

Новые вопросы добавляются в `data.js`.
