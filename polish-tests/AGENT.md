# Инструкция для Claude: как делать тест для ученика

Эта инструкция нужна любому чату Claude, который помогает Насте. Тест = JSON по схеме ниже → черновик в приложении → Настя проверяет и публикует.

## Порядок
1. Прочитать документ ученика (Google Doc «<Имя> mówi po polsku») и найти нужный раздел (тема). Читать свежую версию: документ меняется.
2. Составить 12–20 вопросов: 3–5 заданий по 3–6 вопросов, все три типа (`choice`, `input`, `multi`). Покрыть все подпункты темы, включая исключения.
3. Новые предложения на ту же грамматику, не копировать упражнения из документа дословно. Лексика A2–B1.
4. Неверные варианты — типичные ошибки русскоговорящих. У каждого вопроса однозначный правильный ответ (если допустимы две формы — перечислить обе в `answer` у `input`, спорные варианты не давать в `choice`/`multi`).
5. У каждого вопроса `explanation_ru`: 1–2 предложения по-русски, почему так.
6. Сохранить файл `polish-tests/tests/<тема>-<дата>.json` и проверить: `node -e "console.log(require('./src/schema').validate(require('./tests/<файл>.json'),{strict:true}))"` — должно вывести `[]`.
7. Доставить в приложение (любой способ):
   - вставить JSON в «Панель учителя → Тесты → Загрузить тест (JSON)»;
   - или `node import-sql.js tests/<файл>.json B1` и выполнить SQL в Supabase (проект `polski-quiz`).
   Тест сначала создаётся черновиком, затем проходит проверку и публикацию (см. ниже).

## Проверка и публикация (обязательный порядок)
Тест публикуется автоматически, но только после независимой проверки. Настя при необходимости снимает тест с публикации в приложении.
1. **Слепая проверка.** Запусти отдельного агента (инструмент Agent, тип general-purpose, по возможности самая сильная модель) и передай ему ТОЛЬКО вопросы и варианты, без правильных ответов и без пояснений. Он решает каждый вопрос как носитель польского и по каждому возвращает: ответ, `alt_ok` (есть ли другие допустимые формы) и `problem` (ошибка, неоднозначность, «ни один вариант не подходит», учёт падежа после слова перед пропуском, например «dużo» + родительный).
2. **Сверка.** Сравни ответы проверяющего с твоим ключом. Расхождение или непустой `problem` у вопроса = вопрос исправить (или удалить, если исправить нельзя), затем проверить заново, максимум 2 круга. Допустимые альтернативные формы добавь в `answer` у `input`.
3. **Решение.** Все вопросы прошли → опубликовать (`update public.tests set published = true where id = '<id>'`). Если после 2 кругов остались проблемы → оставить черновиком и записать в `agent_log` kind='question' с перечнем проблем.
4. **Назначение.** Если в названии теста есть имя ученика и в `public.profiles` ровно один ученик с таким `display_name` (без учёта регистра) — назначь ему тест (`insert into public.test_assignments (test_id,user_id) ... on conflict do nothing`). Иначе не назначай и напиши об этом в лог. На `for_all` не публикуй.
5. **Лог.** `insert into public.agent_log (kind,message,test_id) values ('published','Тест «...» проверен независимой проверкой и опубликован<, назначен: Имя>. Если нужно, снимите с публикации.','<id>')`.

## Формат JSON
    {"topic": "Rzeczownik", "student": "Юлия", "created": "ГГГГ-ММ-ДД",
     "tasks": [{"title": "<польский заголовок>", "instruction_ru": "<что делать>",
       "questions": [
         {"id": "q1", "type": "choice", "prompt": "...___...", "options": ["a","b","c"], "answer": "a", "explanation_ru": "..."},
         {"id": "q2", "type": "input", "prompt": "...___ (ona).", "answer": ["nią"], "explanation_ru": "..."},
         {"id": "q3", "type": "multi", "prompt": "...", "options": ["a","b","c","d"], "answer": ["a","b"], "explanation_ru": "..."}]}]}

## Правила
- Задания для ученика на польском, пояснения для Насти и ученицы на русском.
- Не отправлять сообщения и письма ученикам. Публикация теста допустима только после слепой проверки (раздел выше); Настя может снять тест с публикации в приложении.
- Приватность: в репозиторий и в тест — только имя ученика, без фамилий, контактов и данных документов.
- Пароли и ключи не записывать в файлы и не просить в чате.
