# polish-tests — тесты-домашки по польскому из Google Doc

Берёт тему из учебного документа ученицы, генерирует через Claude интерактивный тест, собирает одну HTML-страницу (без внешних зависимостей, работает офлайн после загрузки) и публикует её на GitHub Pages. Зависимостей npm нет: нужен только Node.js ≥ 20.

## Настройка (один раз)

1. **Google.** В Google Cloud Console создайте проект → включите *Google Docs API* → создайте *service account* → скачайте JSON-ключ. В документе «Julia mówi po polsku» нажмите «Поделиться» и дайте адрес из поля `client_email` права **Читателя**.
2. **Anthropic.** Получите API-ключ.
3. **GitHub.** Создайте репозиторий `polish-tests`, в Settings → Pages выберите *Deploy from a branch → main → /docs*. Создайте токен (fine-grained, доступ к этому репозиторию, право *Contents: Read and write*).
   Страницы публичны для всех, у кого есть ссылка: в тестах только имя ученицы, без фамилии.
4. Скопируйте `.env.example` в `.env` и заполните (`GOOGLE_CREDENTIALS` — путь к JSON или сам JSON, `DOC_ID`, `ANTHROPIC_API_KEY`, `CLAUDE_MODEL`, `STUDENT_NAME`, `GITHUB_REPO`, `GITHUB_TOKEN`).

## Тест одной командой

    node cli.js all --topic "zaimki"

Скрипт сгенерирует `tests/zaimki-<дата>.json`, **остановится, чтобы вы проверили и поправили JSON**, затем соберёт страницу и выведет ссылку для ученицы.

## Команды

| Команда | Что делает |
|---|---|
| `node cli.js topics` | список тем документа |
| `node cli.js generate --topic "<тема>" [--questions 15]` | создаёт `tests/<тема>-<дата>.json` (12–20 вопросов) |
| `node cli.js build tests/<файл>.json` | собирает `dist/<тема>-<дата>.html` |
| `node cli.js publish dist/<файл>.html` | кладёт в `docs/<ученица>-<тема>-<дата>.html` репозитория и печатает ссылку |
| `node cli.js all --topic "<тема>"` | всё вместе с паузой на правку JSON |

**Что считается темой.** Если в документе несколько вкладок — каждая вкладка (включая вложенные) это тема. Если вкладка одна — темами становятся заголовки верхнего уровня (Heading 1, а при их отсутствии Heading 2). Новые вкладки и разделы подхватываются автоматически. `--topic` принимает название без учёта регистра и диакритики, допускается часть названия.

## Как устроен тест

- Типы вопросов: `choice` (один верный), `input` (вписать форму), `multi` (отметить все верные). Формат JSON — в `example/zaimki-sample.json`.
- Генерация проверяется схемой: 3–5 заданий, 3–6 вопросов в каждом, 12–20 в сумме, все три типа, у каждого вопроса объяснение на русском. При ошибке запрос повторяется до 2 раз, модель получает список замечаний.
- **Проверка input:** регистр, лишние пробелы и точка в конце игнорируются; польские буквы строгие. Ответ без диакритики (`nia` вместо `nią`) считается ошибкой, но с подсказкой «Почти! Проверь польские буквы: правильно — …». В `answer` можно указать несколько верных вариантов.
- Над каждым полем ввода есть кнопки польских букв.
- «Пройти ещё раз» перемешивает вопросы и варианты.
- Правильные ответы лежат внутри страницы (для домашки это нормально).

## Сбор результатов (необязательно)

Создайте Google Таблицу → Расширения → Apps Script → вставьте `apps-script/Code.gs` → Развернуть как веб-приложение (доступ «Все») → URL в `RESULTS_WEBHOOK_URL` и пересоберите страницу командой `build`. После завершения теста в таблицу уходит строка: дата, ученица, тема, баллы, ошибки. Если запрос не прошёл, ученица всё равно видит результат.

## Проверка

    npm test                      # юнит-тесты (разбор документа, валидация, повторы генерации, публикация, JWT)
    node cli.js build example/zaimki-sample.json && node test/e2e.js   # браузерная проверка (нужен playwright)
