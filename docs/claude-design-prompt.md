# Промпт для Claude Design: визуал приложения «Polski Quiz»

Скопируйте текст ниже в Claude Design. Если есть скриншоты текущего приложения, приложите их как референс «что улучшить».

```
Ты — старший продуктовый дизайнер. Спроектируй визуальный язык и ключевые экраны мобильного веб-приложения для изучения польского языка. Нужен спокойный, дружелюбный и очень понятный интерфейс, на который приятно смотреть каждый день.

КОНТЕКСТ
Приложение для индивидуальных занятий: преподаватель (Настя) ведёт нескольких взрослых русскоговорящих учеников уровня A2–B1 (готовятся к экзамену B1). Ученик заходит с телефона: проходит тесты-домашки, повторяет слова карточками, смотрит результаты. Преподаватель в том же приложении создаёт и проверяет тесты, добавляет учеников, смотрит прогресс. Язык интерфейса — русский, учебный контент — польский (используются буквы ą ć ę ł ń ó ś ź ż, шрифт обязан их красиво отображать). Приложение работает в браузере, mobile-first (390 px), на компьютере — тот же интерфейс в колонке до 720 px.

ХАРАКТЕР И НАСТРОЕНИЕ
Тёплый, спокойный, уверенный, «как хороший репетитор». Не детский и не геймифицированный до крика, не корпоративно-холодный. Ощущение порядка и лёгкости. Можно тонко намекнуть на Польшу (белый и красный как редкие акценты), но без флагов, орлов и клише.

ЦВЕТ И ТИПОГРАФИКА
- Светлая и тёмная темы, одинаково продуманные. Основа нейтральная (тёплый или холодный серый фон, белые/тёмные карточки).
- Один фирменный акцентный цвет для главных действий и активных состояний + мягкая тонированная версия для фонов. Отдельные семантические цвета: верно (зелёный), ошибка (красный), «почти» (янтарный). Все пары текст/фон — не хуже WCAG AA.
- Шрифт без засечек с отличной кириллицей и польской диакритикой (например Inter, Manrope или похожий), 2–3 размера заголовков, комфортный основной 16 px, мелкий 13–14 px только для вторичного текста.
- Предложи 2–3 варианта палитры и один рекомендуй.

ЭКРАНЫ (показать на 390 px; 2–3 ключевых и на десктопе)
Ученик:
1. Вход (email + пароль, кнопка «глаз» показать пароль).
2. Главная «Задания»: приветствие по имени, блок «Новые задания» (карточка с названием, коротким описанием, меткой «Новое»), плитка «Повторить слова» (сколько на сегодня), «Пройденные» с результатом вроде «✓ 15/19».
3. Прохождение теста: один блок заданий на экране, индикатор прогресса, три типа вопросов: выбор одного ответа, отметить все верные (чекбоксы), вписать слово (над полем ряд кнопок с польскими буквами). Состояния: до проверки, после проверки (верно/ошибка/«Почти! проверь польские буквы») с коротким пояснением на русском.
4. Результат: крупный балл, мотивирующая фраза, список ошибок с правильными ответами и пояснениями.
5. Карточки слов: польское слово крупно, кнопка озвучки, «Показать перевод», затем «Знал / Не знал», пример предложения.
6. Результаты: список прохождений с оценкой-чипом.
Преподаватель:
7. Тесты: список строками (название, уровень A2/B1, число вопросов, статус «опубликован/черновик»), блок «Помощник сообщает» с кнопкой «Снять с публикации».
8. Редактор теста: основные поля, раскрывающийся блок «Кому доступен», раскрывающиеся карточки вопросов.
9. Ученики: раскрывающиеся строки учеников (аватар с инициалами, имя, email, счётчик «2 из 5 тестов»), внутри чекбоксы тестов и кнопки действий (новый пароль, ссылка, удалить).
10. Слова: прогресс каждого ученика (полоса, «сегодня 12 ответов, верно 9», «не даются: …»), поиск по словарю, список слов с правкой.
11. Экран «Приглашение ученику» (готовый текст для копирования + кнопки).

ЭЛЕМЕНТЫ
Нижняя плавающая навигация (3 пункта у ученика, 5 у преподавателя, компактная, не растянутая), шапка с аватаром и меню «⋯», карточки и списки со скруглениями и мягкой тенью, чипы статусов, кнопки (основная, второстепенная, опасная), поля ввода, раскрывающиеся панели, пустые состояния с подсказкой «что делать», сообщения об ошибках и успехе.

ТРЕБОВАНИЯ
- Крупные зоны нажатия (≥ 44 px), читаемость на улице, всё работает одной рукой.
- Много воздуха, не более одного главного действия на экран, сильная иерархия.
- Единая сетка отступов (4/8 px), единые радиусы.
- Микровзаимодействия описать словами: раскрытие панели, подсветка ответа, появление результата. Без лишних анимаций.
- Избегай: градиентных «неонов», тяжёлых теней, декоративных иллюстраций, перегруженных иконок, мелкого серого текста на сером.

РЕЗУЛЬТАТ
1) Дизайн-токены: цвета (светлая/тёмная), шрифты и размеры, отступы, радиусы, тени. 2) Библиотека компонентов с состояниями. 3) Макеты перечисленных экранов. 4) Короткое обоснование выбора и 2–3 идеи, как сделать приложение запоминающимся без перегруза.
```
